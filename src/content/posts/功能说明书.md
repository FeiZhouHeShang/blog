# 博客文章功能说明书

> 📌 本文件是功能说明书，不会被前端渲染，也不会出现在后台文章列表。仅供维护者参考。

## 一、文件夹用途

`src/content/posts/` 里**每一条 `.md` = 一篇文章**。在后台加文章即网站多一篇。

## 二、字段说明

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| **title** | ✅ | 文章标题 | `我的第一篇` |
| **published** | ✅ | 发布日期 `YYYY-MM-DD` | `2026-07-30` |
| **body** | ✅ | 正文（富文本编辑器，支持各种块） | — |
| **description** | 否 | 摘要，留空自动截取正文 | `这是摘要` |
| **image** | 否 | 封面图路径 | `/images/xx.png` |
| **tags** | 否 | 标签（多选，可新建） | `前端` |
| **category** | 否 | 分类 | `教程` |
| **draft** | 否 | 草稿（true 则不公开） | `false` |
| **pinned** | 否 | 置顶 | `false` |
| **updated** | 否 | 更新日期 | `2026-07-31` |
| **lang** | 否 | 语言（空=中文，可选 en/ja/zh_TW/ru） | `en` |
| **author** | 否 | 作者（覆盖默认） | `小明` |
| **comment** | 否 | 是否开启评论（默认开） | `true` |
| **password** | 否 | 访问密码（留空公开） | — |

## 三、如何添加 / 修改 / 删除

- 后台「📝 内容页面」→「📝 博客文章」→ 新建 / 点开编辑 / 删除
- 新建时文件名自动用标题生成，不用手填

## 四、完整案例

```text
---
title: 我的第一篇博客
published: 2026-07-30
description: 这是摘要
image: /images/cover.png
tags:
  - 前端
  - 教程
category: 教程
draft: false
pinned: false
comment: true
---

这里是正文，支持 **加粗**、[链接](https://example.com)、代码块等。
```

## 五、标签 / 分类从哪来

标签和分类由构建脚本 `scripts/gen-posts-index.mjs` 自动从所有文章聚合，
后台下拉直接选，也能「+ 新建」。改完文章后这些下拉会自动更新。
