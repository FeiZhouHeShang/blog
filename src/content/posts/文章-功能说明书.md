# 博客文章功能说明书 · 萌新版

> 📌 功能说明书，不会被前端渲染，也不会出现在后台文章列表。仅供维护者参考。
> 文件名带功能前缀（文章-功能说明书.md），方便在文件夹里一眼找到。

## 一、文件夹用途

`src/content/posts/` 里**每一条 `.md` = 一篇文章**。在后台加文章即网站多一篇。
可建子文件夹分类（如 `posts/ai/`、`posts/projects/`），不影响使用。

## 二、字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| **title** | ✅ | 文章标题 |
| **published** | ✅ | 发布日期 `YYYY-MM-DD` |
| **body** | ✅ | 正文（富文本编辑器，支持各种块） |
| **description** | 否 | 摘要，留空自动截取正文 |
| **image** | 否 | 封面图路径 |
| **tags** | 否 | 标签（多选，可新建） |
| **category** | 否 | 分类 |
| **draft** | 否 | 草稿（true 则不公开） |
| **pinned** | 否 | 置顶 |
| **updated** | 否 | 更新日期 |
| **lang** | 否 | 语言（空=中文，可选 en/ja/zh_TW/ru） |
| **author** | 否 | 作者（覆盖默认） |
| **comment** | 否 | 是否开启评论（默认开） |
| **password** | 否 | 访问密码（留空公开） |

## 三、如何添加 / 修改 / 删除

- 后台「📝 内容页面」→「📝 博客文章」→ 新建 / 点开编辑 / 删除
- 新建时文件名自动用标题生成，不用手填

## 四、完整案例（✅ 直接复制，改中文即可）

> 提示：下面整段可一键复制，`#` 是注释，保留也不影响使用。

```yaml
---
title: 我的第一篇博客          # 【标题】必填。文章的标题
published: 2026-07-30         # 【发布日期】必填。格式 年-月-日
description: 这是摘要          # 【摘要】可选。留空自动截取正文前几句
image: /images/cover.png      # 【封面图】可选。文章列表/详情页封面
tags:                         # 【标签】可选。每行一个，后台也能多选/新建
  - 前端                      #   标签1
  - 教程                      #   标签2
category: 教程                # 【分类】可选。
draft: false                  # 【草稿】true = 不公开（仅自己可见）；false = 正常发布
pinned: false                 # 【置顶】true = 文章列表置顶
updated: 2026-07-31           # 【更新时间】可选。
lang: ""                      # 【语言】可选。空=中文；en/ja/zh_TW/ru
author: 小明                  # 【作者】可选。留空用默认作者
comment: true                 # 【评论】true = 开启评论；false = 关闭
password: ""                  # 【访问密码】可选。留空=公开；填了需密码才能看
---

这里是正文，支持 **加粗**、[链接](https://example.com)、代码块等 Markdown 语法。
```

## 五、标签 / 分类从哪来

标签和分类由构建脚本 `scripts/gen-posts-index.mjs` 自动从所有文章聚合，
后台下拉直接选，也能「+ 新建」。改完文章后这些下拉会自动更新。
