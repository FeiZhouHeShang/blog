# 日常吐槽（说说）功能说明书

> 📌 本文件是「功能说明书 / 维护手册」，**不会被前端渲染**，也**不会出现在后台编辑列表**。
> 它只是放在功能文件夹里给维护者（和未来的你）看的操作指南。改它不会影响网站任何展示。

## 一、这个文件夹是干嘛的

`src/content/moments/` 里**每一条 `.md` 文件 = 一条说说**。
在后台加一条 → 网站「日常吐槽」信息流多一条；删一条 → 少一条。
所有编辑都在后台 PagesCMS 完成，**不用碰代码**。

## 二、字段说明（一条说说能填什么）

| 字段 | 必填 | 说明 | 示例 |
|------|------|------|------|
| **正文 (body)** | ✅ | 文件最底下、两个 `---` 下面的那段文字，支持 Markdown | `今天天气真好` |
| **date** | 否 | 发布时间 `YYYY-MM-DD HH:mm`（24 小时制，空格分隔） | `2026-07-30 21:30` |
| **location** | 否 | 地点，显示在时间旁边 | `杭州` |
| **tags** | 否 | 标签列表，每条一个；页面显示成 `#标签` | `测试` |
| **pinned** | 否 | 是否置顶（勾选后固定在信息流顶部「📌 置顶」区） | `false` |
| **images** | 否 | 图片地址列表，每行一张，最多 9 张 | `https://...png` |
| **videos** | 否 | 视频直链列表（mp4/webm），每行一个 | `https://...mp4` |

> 最少只需写「正文」就能发一条；其它都是锦上添花。

## 三、如何添加一条新说说

1. 打开后台 PagesCMS → 「🔧 功能配置」→「💬 日常吐槽（说说）」
2. 点「新建 / New」，填一个**英文短文件名**（如 `my-first`，不用带 `.md`）
3. 在「正文」里写内容；需要的话再填时间 / 地点 / 标签 / 图片 / 视频
4. 保存 → 等几十秒 Vercel 自动重建，线上就出现了

## 四、如何修改 / 删除

- **修改**：后台列表点开那条 → 改字段 → 保存
- **删除**：进那条 → 右上角「删除」（删除后线上同步消失）

## 五、图片 / 视频怎么填

- **图片**：图床外链（`https://...`）直接粘；或后台「站点资源 → 日常吐槽图片」上传后填本地路径
- **视频**：填 **能直接在浏览器播放的 mp4/webm 直链**（B 站/腾讯视频的网页链接不行，要找「直链」）
- 页面上图片是固定小缩略图（点开看大图），视频是深色 ▶ 缩略图（点了才加载播放，省流量）

## 六、完整功能案例（复制下面整段，改成你自己的内容即可）

下面这条用上了「文字 + 标签 + 地点 + 图片 + 视频 + 不置顶」：

```text
---
date: 2026-07-30 21:30
location: 测试
tags:
  - 测试
  - 新功能
pinned: false
images:
  - https://tc.d15.cc.cd/file/日常吐槽/_YM0Y__NEN9G_DQ_VQ_RTWM.png
videos:
  - https://tencentcdn.production.link3.cc/files/upload_video/link3_1721236315623/uploadvideo_1721238922179.mp4
---

**测试新说说样式** —— 文字为主，下面会显示一张图片缩略图（点击放大看）和一个视频缩略图（点击后加载播放）。
- 图片固定小缩略图，永远不会撑爆卡片
- 视频不预加载，点击 ▶ 才加载，省流量
- 灯箱支持 ◀ ▶ 切换、ESC 关闭、背景点击关闭
```

> 案例里的图片/视频是测试素材，正式内容请换成你自己的地址。
