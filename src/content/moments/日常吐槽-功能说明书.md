# 日常吐槽（说说）功能说明书 · 萌新版

> 📌 本文件是「功能说明书 / 维护手册」，**不会被前端渲染**，也**不会出现在后台编辑列表**。
> 它只是放在功能文件夹里、给你（和未来的你）看的操作指南。改它不会影响网站任何展示。
> 文件名带功能前缀（日常吐槽-功能说明书.md），方便在文件夹里一眼找到。

## 一、这个文件夹是干嘛的

`src/content/moments/` 里**每一条 `.md` 文件 = 一条说说**。
在后台加一条 → 网站「日常吐槽」信息流多一条；删一条 → 少一条。
所有编辑都在后台 PagesCMS 完成，**不用碰代码**。

## 二、⚠️ 最容易搞混的两件事（一定要先看这里）

1. **说说没有独立的「标题」字段！**
   标题就是你写在**正文第一行**的那个加粗文字（用 `**文字**`）或 `# 标题`。
   比如你这条案例里，`**测试新说说样式**` 就是标题——它写在 `---` 下面、正文最开头。

2. **`location` 不是标题，是「发布地点」**
   它显示在时间旁边（例如 `· 杭州`）。
   你案例里 `location: 测试` 和 `tags` 里的 `- 测试` 是**两回事**：
   - `location: 测试` → 地点叫"测试"
   - `tags: - 测试` → 一个叫"测试"的标签
   两个都写"测试"只是你举例时凑巧用了同一个词，平时它们含义不同。

## 三、字段说明（一条说说能填什么）

| 字段 | 必填 | 说明 | 显示在哪 |
|------|------|------|----------|
| **正文 (body)** | ✅ | `---` 下面那段文字，支持 Markdown；第一行通常就是标题 | 卡片主体 |
| **date** | 否 | 发布时间 `YYYY-MM-DD HH:mm`（24 小时制，空格分隔） | 头像下方时间 |
| **location** | 否 | 发布地点，显示在时间右边（`· 地点`） | 时间右侧 |
| **tags** | 否 | 标签列表，每条一个；页面显示成 `#标签` | 卡片底部 |
| **pinned** | 否 | 是否置顶（true 固定在顶部「📌 置顶」区） | 置顶区 |
| **images** | 否 | 图片地址列表，每行一张，最多 9 张 | 小缩略图网格 |
| **videos** | 否 | 视频直链列表（mp4/webm），每行一个 | 深色 ▶ 缩略图 |

> 最少只需写「正文」就能发一条；其它都是锦上添花。

## 四、如何添加一条新说说

1. 打开后台 PagesCMS → 「🔧 功能配置」→「💬 日常吐槽（说说）」
2. 点「新建 / New」，填一个**英文短文件名**（如 `my-first`，不用带 `.md`，要唯一）
3. 在「正文」里写内容；需要的话再填时间 / 地点 / 标签 / 图片 / 视频
4. 保存 → 等几十秒 Vercel 自动重建，线上就出现了

## 五、如何修改 / 删除

- **修改**：后台列表点开那条 → 改字段 → 保存
- **删除**：进那条 → 右上角「删除」（删除后线上同步消失）

## 六、图片 / 视频怎么填

- **图片**：图床外链（`https://...`）直接粘；或后台「站点资源 → 日常吐槽图片」上传后填本地路径
- **视频**：填 **能直接在浏览器播放的 mp4/webm 直链**（B 站/腾讯视频的网页链接不行，要找「直链」）
- 页面上图片是固定小缩略图（点开看大图），视频是深色 ▶ 缩略图（点了才加载播放，省流量）

## 七、完整功能案例（✅ 直接复制下面整段，改成你自己的内容就能用）

> 提示：下面整段（包括每行后面的 `# 说明`）都可以**一键复制**粘贴成一个新的 `.md` 文件。
> `#` 是 YAML 注释，复制后保留也没关系，不影响使用；你只改中文/链接即可。

```yaml
---
date: 2026-07-30 21:30        # 【发布时间】格式：年-月-日 时:分（24小时制，空格分隔）。留空显示"刚刚"，排序也按它倒序。
location: 测试                # 【发布地点】可选。填城市/地点，会显示在时间旁边，例如"杭州"。注意：这不是标题！
tags:                         # 【标签】可选。下面每行写一个标签；页面显示成 #标签
  - 测试                      #   标签1（举例：标注"测试"）
  - 新功能                    #   标签2（举例：标注"新功能"）
pinned: false                 # 【是否置顶】true = 固定在顶部"📌 置顶"区；false = 正常
images:                       # 【图片】可选。下面每行一个图片地址，最多 9 张
  - https://tc.d15.cc.cd/file/日常吐槽/_YM0Y__NEN9G_DQ_VQ_RTWM.png   #   图片地址（图床外链或后台上传后的本地路径）
videos:                       # 【视频】可选。下面每行一个 mp4/webm 直链
  - https://tencentcdn.production.link3.cc/files/upload_video/link3_1721236315623/uploadvideo_1721238922179.mp4  #   视频直链，点击缩略图才加载播放（省流量）
---

**测试新说说样式** —— 这就是这条说说的"标题"（写在正文第一行，用 **加粗** 或 # 标题 都行）。
下面是正文内容，文字为主：
- 图片固定小缩略图，点击放大看
- 视频不预加载，点击 ▶ 才加载，省流量
- 灯箱支持 ◀ ▶ 切换、ESC 关闭、背景点击关闭
```

> 案例里的图片/视频是测试素材，正式内容请换成你自己的地址。
> 仓库里现有的 `test-video-001.md` 就是这条案例的「活样本」，可对照参考。
