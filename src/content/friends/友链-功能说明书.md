# 友链（友情链接）功能说明书

## 这是什么
友链列表展示在 `/friends/` 页面，每条是一个站点的「名称 + 头像 + 描述 + 链接」。
数据存在本文件夹（`src/content/friends/`），**每个友链一个 `.md` 文件**，
由后台 PagesCMS 的「🔗 友链数据」集合管理——萌新零代码，在后台增删改即可，提交后 Vercel 自动重建上线。

## 字段说明（每个 .md 顶部的 frontmatter）
- `title`    站点名称（**必填**，页面显示的名字）
- `imgurl`   站点头像 / Logo 的 URL（**必填**，显示头像）
- `desc`     一句话描述（**必填**，页面显示的描述）
- `siteurl`  站点链接（**必填**，点击跳转的目标地址）
- `tags`     分类标签数组（可选），用于页面顶部筛选
- `weight`   权重数字（可选，默认 5，越大越靠前）
- `enabled`  是否启用（可选，默认 true；设 false 可临时隐藏，不删除）

## 如何添加一条友链（后台，零代码）
1. 打开后台「🔗 友链数据」集合 → 点「新建」，文件名填一个英文短名（如 `my-friend`，不带 `.md`）。
2. 填写 `title` / `imgurl` / `desc` / `siteurl`（其余可选）。
3. 保存 → 等 Vercel 自动部署完成 → 友链即在 `/friends/` 上线。

## 如何修改 / 删除
- 修改：后台找到该条目直接改字段保存。
- 删除：后台删除该条目即可；或把 `enabled` 取消勾选 → 临时隐藏（数据保留，随时可恢复）。

## 客人怎么申请友链（申请入口）
- 客人在 `/friends/` 点「如何申请友链」→ 弹窗里有「本站信息」和申请模板。
- 申请入口由 `src/config/friendsConfig.ts` 的 `applyLink` 决定：
  - 留空：客人只能按模板在页面说明里自行联系你；
  - 填了（如腾讯文档 / 飞书表单链接）：弹窗会出现「自助申请友链（推荐）」按钮，客人走表单提交，你邮箱收通知。
- 你审核通过后，按上面「如何添加」在后台加一条即可。

## 完整功能案例（可直接复制，改内容就能用）
下面整段是**一个友链文件的完整写法**，每行带 `#` 注释；`#` 注释保留也不影响使用，可一键复制。

```yaml
title: 非洲和尚的技术窝          # 【站点名称】必填，页面上显示的友链名字
imgurl: https://example.com/logo.png   # 【头像/Logo】必填，头像图片地址（图床外链或后台上传）
desc: 一个分享前端与折腾记录的小站   # 【描述】必填，一句话介绍这个站点
siteurl: https://example.com     # 【站点链接】必填，点击跳转的目标地址（要带 http/https）
tags:                            # 【标签】可选，用于页面筛选，每行一个
  - 技术
  - 博客
weight: 8                        # 【权重】可选，数字越大越靠前，默认 5
enabled: true                    # 【启用】可选，默认 true；设 false 可临时隐藏该友链
```

> 提示：`imgurl` 也可在后台「站点资源 → 友链头像」上传图片后自动填入路径，不必手敲外链。
