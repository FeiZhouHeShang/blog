# 站点单页（关于 / 友链 / 留言板 / 隐私 / 协议）功能说明书 · 萌新版

> 📌 功能说明书，不渲染、不进后台列表，仅供维护者参考。
> 文件名带功能前缀（单页记录-功能说明书.md），方便在文件夹里一眼找到。

## 一、文件夹用途

`src/content/spec/` 存放**整站的单页内容**，每个文件对应一个固定页面：

| 文件 | 对应页面 | 后台入口 |
|------|----------|----------|
| `about.md` | 关于页 | 内容页面 → 关于页面 |
| `friends.md` | 友链页 | 内容页面 → 友情链接 |
| `guestbook.md` | 留言板页 | 内容页面 → 留言板 |
| `privacy.md` | 隐私政策 | 内容页面 → 隐私政策 |
| `user-agreement.md` | 用户协议 | 内容页面 → 用户协议 |

> 友链的**具体站点列表**在「🔧 功能配置 → 🔗 友链数据」(`src/config/friendsConfig.ts`) 维护，
> 本文件夹的 `friends.md` 只承载标题 / 描述等页面元信息。

## 二、字段说明（这些页面通用）

| 字段 | 必填 | 说明 |
|------|------|------|
| **title** | 否 | 页面标题（留空有默认值，如"关于我"） |
| **description** | 否 | 页面描述 |
| **body** | 否 | 正文（富文本），放页面说明文字 |

> 这类页面 frontmatter 较自由，按需加减字段即可；正文用富文本编辑器写。
> 注意：单页有独立的 `title` 字段（在 `---` 里），**不是**像说说那样靠正文第一行当标题。

## 三、如何修改

后台「📝 内容页面」→ 对应页面 → 改正文 / 标题 → 保存。

## 四、完整案例（以关于页为例，✅ 直接复制）

> 提示：下面整段可一键复制，`#` 是注释，保留也不影响使用。

```yaml
---
title: 关于我                 # 【页面标题】可选。留空用默认值"关于我"
description: 这个博客是关于什么的   # 【页面描述】可选。
---

这里是「关于我」的正文内容，可以写经历、爱好、联系方式等 Markdown 文字。
```
