# 日常吐槽（说说）后台编辑说明

> 目标：让你**不碰代码**，只在后台（PagesCMS）就能发/改/删「日常吐槽 / 说说」。
> 页面效果参考 [blog.tsh520.cn/moments](https://blog.tsh520.cn/moments/) 的「说说」信息流 1:1 复刻。
> 配套代码：`src/content/moments/*.md`（数据）、`src/content.config.ts` 的 `moments` 集合（字段规则）、`src/pages/moments.astro`（页面渲染）、根目录 `.pages.yml` 的 `moments` 集合配置。

---

## 一、数据存在哪

每条「说说」是一个 Markdown 文件，放在：

```
src/content/moments/<文件名>.md
```

文件长这样（后台会自动生成，你基本不用看源码）：

```markdown
---
date: 2026-07-30 21:30
location: 杭州
tags:
  - 测试
pinned: false
images:
  - https://图床地址/xxx.png
---

今天写完了日常吐槽的后台编辑功能，发条说说纪念一下～
```

---

## 二、在后台发一条新说说（最常用）

1. 打开 PagesCMS 后台 → 左侧「**内容页面**」分组 → 点「**💬 日常吐槽（说说）**」。
2. 右上角点「**新建**」。
3. 填 **文件名**：用英文短标识，例如 `grumble-0730-2130`（**不用带 .md**）。
   它是这条说说的锚点 id，请保持**唯一**（重复会覆盖旧的那条）。
4. 填写字段（见下表），最少只需填「**正文**」就能发。
5. 点「**保存**」→ 后台会把改动提交到 GitHub → Vercel 自动重建 → 线上生效（通常几十秒到一两分钟）。

### 字段说明

| 字段 | 是否必填 | 说明 | 示例 |
|------|----------|------|------|
| **正文** | ✅ 必填 | 说点什么，支持 Markdown。回车分段；`**加粗**`、`[文字](地址)`、`` `代码` `` 都支持 | `今天天气真好` |
| **发布时间** | 可选 | `YYYY-MM-DD HH:mm`（24 小时制，空格分隔）。留空显示「刚刚」，排序也按它倒序 | `2026-07-30 21:30` |
| **地点** | 可选 | 显示在时间旁边 | `杭州` |
| **标签** | 可选 | 点「+ 添加」逐个加，回车确认。页面以 `#标签` 展示 | `测试`、`吐槽` |
| **置顶** | 可选 | 勾选后固定在信息流顶部「📌 置顶」区 | — |
| **图片** | 可选 | 见下方「图片怎么加」 | — |
| **视频** | 可选 | 见下方「视频怎么加」 | — |

## 三、图片怎么加

两种方式，任选其一（每行一张，最多 9 张，页面自动排成小缩略图，**点击任意一张进入全屏灯箱放大看**，微信朋友圈 / QQ空间 那种感觉）：

**方式 A：图床外链（推荐，省仓库空间）**
1. 先把图片传到你的图床，拿到以 `https://` 开头的直链。
2. 在「图片」字段点「+ 添加」，把链接粘进「图片地址」。

**方式 B：上传到本站仓库（本地加载，不依赖图床）**
1. 后台左侧「**站点资源**」→「**日常吐槽图片**」。
2. 上传图片，上传后复制它的路径（形如 `/assets/images/moments/xxx.png`）。
3. 回到说说编辑，把该路径填进「图片地址」。

> 两种方式混用也行；图片地址既可以是外链也可以是本地路径。

---

## 四、视频怎么加

和图片类似，但只填 **mp4 / webm 直链**（点开后能直接在浏览器播放的链接，比如自己的 OSS / COS / 又拍 / B 站视频的源链接）。

操作：
1. 在「视频」字段点「+ 添加」，粘贴视频直链到「视频地址」。
2. 页面上视频以 **深色 ▶ 缩略图** 呈现（不像图片那样有预览）。
3. 用户点击缩略图后，**才** 在全屏灯箱里加载并播放（不预加载，省流量）。
4. 视频和图片会**混排在同一个网格**里，所以一条说说里同时放图和视频，缩略图会按你填的先后顺序排列。

> 没有合适的视频直链？也可以先把视频传到本站「**站点资源 → 日常吐槽图片**」目录下的 mp4 文件，拿到 `/assets/images/moments/xxx.mp4` 这种路径填进来（PagesCMS 媒体库目前对视频文件大小没特别限制，但仓库别超过 100 MB）。

## 五、修改 / 删除一条说说

- **修改**：后台「💬 日常吐槽（说说）」列表里点对应那条 → 改字段 → 保存。
- **删除**：进那条说说 → 右上角「**删除**」（删除后同样会触发重建，线上同步消失）。

---

## 六、排序与置顶规则

- 信息流顺序：**置顶的永远在最前**，其余按「发布时间」**倒序**（新的在上）。
- 想让某条长期靠前：勾「置顶」。
- 同一条改时间只会改变它在非置顶区的相对位置。

## 七、常见问题（FAQ）

**Q：保存后线上没立刻变？**
A：后台保存 = 提交到 GitHub，Vercel 需要几十秒~一两分钟重建。稍等刷新即可；若超过 5 分钟还没变，去 Vercel 看构建是否报错。

**Q：时间显示成「刚刚 / X 分钟前」而不是具体日期？**
A：这是页面按发布时间算的**相对时间**（和参考站一致）。超过 30 天会显示具体日期。想看精确时间，把鼠标悬停在时间上（浏览器原生 title）。

**Q：Markdown 没生效？**
A：确认「正文」字段里用的是标准 Markdown 语法；富文本里直接回车就是分段。

**Q：图片不显示？**
A：先确认图片地址能浏览器直接打开。图床外链注意是否过期/防盗链；本地路径确认上传成功且路径拼写正确（区分大小写）。

**Q：图片点击没反应 / 灯箱打不开？**
A：先确认浏览器禁用了 JavaScript（灯箱需要 JS）；否则就是图片本身加载失败（404），浏览器不会拦截点击但灯箱打开是空图。

**Q：视频点不开 / 灯箱里一直转圈？**
A：99% 是视频链接本身不能直接播。常见原因：① 链接是页面而非视频文件（如 B 站视频页 URL 而非源 mp4）；② 视频需要登录 / 鉴权；③ 服务器防盗链 Referrer 不允许本站域名。**直接在浏览器地址栏粘贴你的视频 URL 验证**——能直接播放就是直链，不能就是普通网页。

**Q：想让图片/视频整页更紧凑些？**
A：这是 CSS 决定的，当前固定小缩略图是按微信/QQ 体验调的。如果想自定义，去 `src/pages/moments.astro` 的 `.ss-imgs--1/--2/--3` 改宽度。

**Q：想换头像 / 昵称 / 签名？**
A：那是全站个人信息，不在说说里改——改 `src/config/homeConfig.ts` 的 `avatar` / `displayName` / `bio`（或参考 `ProfileCard.astro` 顶部注释）。

## 八、给开发者的备注（可选读）

- 字段 schema 在 `src/content.config.ts` 的 `momentsCollection`：`date/location/tags/pinned/images/videos`，正文走 Markdown body。
- `tags` / `images` / `videos` 在后台以「列表」编辑，PagesCMS 可能序列化为标量数组（`["a"]`）或对象数组（`[{tag:"a"}]`）；
  页面用 `normList()` 统一拍平，两种形态都能正确渲染，无需操心。
- 页面渲染在 `src/pages/moments.astro`：媒体网格用微信/QQ 风格的固定小缩略图（`ss-imgs--1/--2/--3`），文字（`.ss-card-content`）是主体。
- 灯箱（lightbox）逻辑在页面底部 `<script>`：`a.ss-img[data-type="image"]` 与 `.ss-video-thumb[data-type="video"]` 的点击走 document 委托；同卡片内多张可 ◀ ▶ 切换，ESC / 背景点击 / × 关闭。
- Swup 软导航兼容性：`astro:before-swap` 关闭灯箱；`astro:page-load` 重新绑定灯箱按钮（lb 元素每次导航是新的）。
- 视频 **不预加载**：src 只在灯箱打开时设置；用户不点就不消耗流量。
- 前台「我要吐槽」编辑器已于 2026-07-30 移除，编辑全部收归后台，避免重复入口与令牌安全隐患。
