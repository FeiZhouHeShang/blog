## 八、特色功能模块详解

### 8.1 影视与游戏（movies-games）◑ 记忆 + ✓ 数据文件存在
- 入口：`/movies-games/`（导航「记录」子项，`LinkPreset.MoviesGames=21`，图标 `material-symbols:movie`）。
- 数据：`src/data/movies-games.ts`（17 条示例，封面热链，破图兜底）。
- 编辑双通道：①前端 `<dialog>` 编辑器（GitHub Contents API：GET sha+base64→解析→PUT；PAT 仅存 localStorage，绝不烘焙）；② GitHub 编辑回链兜底。
- 智能匹配：TMDB `search/multi` → 自动填 title/cover/comment/section（`inferSection` 映射 tv/movie/anime…）。
- 凭据分界：TMDB 只读令牌 ✅ 烘焙进 `editorSecrets.ts`；GitHub PAT ❌ 仅 localStorage。

### 8.2 日常吐槽（moments / daily-grumble）◑ 记忆 + ✓ 数据/脚本存在
- 入口：`/moments/`（`LinkPreset.DailyGrumble=20`，图标 `material-symbols:chat-bubble`）。
- 数据：`src/data/daily-grumble.ts`；图片走 CloudFlare ImgBed（`https://tc.d15.cc.cd`）。
- 编辑：同 movies-games 的 GitHub Contents API 模式 + 前端 dialog + PAT。
- **图床查重三层**（ded03e4 落地）：①localStorage 跨会话索引（30 天 TTL）；②可选跨浏览器（`imageBedApiToken` 启用 `/api/manage/list`，5 分钟内存缓存）；③会话内 SHA-256 防双击。
- 验证脚本齐全：`scripts/_test_imgbed_dedup.mjs` `scripts/_verify_moments_dedup.mjs` 等。

### 8.3 天气组件（WeatherWidget）◑ 记忆
- 定位链路：`/api/ip9.json`（CF Worker 代理）→ vore.top → pconline → ipwho.is；`GEO_FIXED` 默认 null（真实访客定位）。
- 天气源：uapis `weather?...&lang=zh`，30 分钟 localStorage 缓存；`<style is:global>` + `[data-weather-widget]` 限定（动态 innerHTML 不吃 scoped）。
- 失败兜底：try/catch + 「获取失败」占位，不崩页。

### 8.4 布局与导航（MainGridLayout + 侧栏）◑ 记忆
- `MainGridLayout.astro` 用 `Astro.slots.has("sidebar-left"/"sidebar-right")` 自动设 `data-sidebar-position`（both/left/right/none），`grid.css` 切 3/2/1 栏 + sticky；`--sidebar-width:280px`；响应式 <1280 隐右栏、<1024 隐全部。
- 导航顺序（✓ `navBarConfig.ts` 确认）：**文章 → 记录(交友互动) → 关于(我的)** 三大下拉；动态（日常吐槽）独立；相册已从「动态」迁「记录」。
- 留言板 `guestbook.astro` 自带仿聊天面板，**不接左右侧栏**（避免三栏重叠）。

### 8.5 AI 语义搜索（RAG）✓ 已核对 worker/server/scripts
- 前端：`components/controls/ai-search/`（Svelte + SSE 流式解析）。
- SSR：`src/server/ai-search/`（OpenAI 兼容 provider、SSE、prompt、errors）。
- Worker：`src/workers/cloudflare/ai-search/`（vectorize-retriever、workers-ai-provider/stream、durable-rate-limiter）。
- 索引：`scripts/ai-search/build-index.ts`（`pnpm build-index`，Cloudflare Vectorize `blog-ai-search`，dimensions 1024）。
- `wrangler.jsonc` 印证：vectorize 绑定 + AI 绑定 + Durable Object 限流。

### 8.6 留言板（Guestbook）✓ 已核对 guestbookConfig
- QQ 群聊风格，复用 Waline 登录/审核/评论数据；固定 `/guestbook/` 频道，无需 KV/Worker。
- `guestbookConfig.ts` 存规则公告（法律法规/审核提示等）。

### 8.7 其他页面模块

## 十二、快速上手与维护命令

```bash
pnpm install          # 安装依赖
pnpm dev              # 开发服务器（astro dev）

pnpm build-index      # 构建/更新 AI 向量索引（需 CLOUDFLARE_API_TOKEN）
pnpm test             # vitest 单测（含图床查重等）
```
